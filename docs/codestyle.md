# Руководство по стилю кода и коммитам

## Стилизация кода (Code Styling)

В проекте используется инструмент `Ruff` для статического анализа и автоматического форматирования Python-кода.

### Основные правила:
1. **Длина строки**: Максимум 100 символов.
2. **Кавычки**: Для строк используются только **двойные кавычки** (`"double quotes"`). Одинарные кавычки допускаются только внутри строк во избежание экранирования.
3. **Импорты**: Сортировка импортов осуществляется автоматически через встроенный модуль `isort` в Ruff:
   - Импорты группируются (стандартные библиотеки, сторонние пакеты, локальные модули).
   - Импорты внутри секций сортируются по алфавиту.
   - Используется `combine-as-imports = true`.
4. **Исключения**:
   - В тестах (`tests/*`) разрешено использование утверждений `assert` (отключено правило `S101`).
   - В скриптах (`scripts/*`) разрешено использование `print` (отключено правило `T201`).

### Команды для проверки и форматирования:
- Проверить стиль: `make lint`
- Отформатировать код: `make format`

## Стандарты коммитов (Conventional Commits)

Мы следуем соглашению **Conventional Commits** (без использования скобок областей/scopes) для структурирования истории изменений. Описания в коммитах пишутся исключительно на русском языке.

### Формат сообщения коммита:
```
<тип>: <краткое описание изменения на русском языке>

[необязательное более подробное описание]
```

### Основные типы коммитов (`<type>`):
- `feat` — Добавление нового функционала.
- `fix` — Исправление багов.
- `docs` — Изменения в документации (README, папка `docs`).
- `style` — Правки стиля кода (пробелы, форматирование, кавычки — без изменения логики).
- `refactor` — Правки кода, улучшающие структуру/читаемость, но не добавляющие фичи и не исправляющие баги.
- `test` — Добавление или изменение тестов.
- `chore` — Обновление зависимостей, рутинные задачи, конфигурация сборщиков/линтеров (Makefile, .gitignore, pre-commit).

### Примеры:
- `chore: добавить конфигурацию gitignore`
- `chore: настроить pyproject.toml и ruff`
- `docs: добавить руководство по запуску на windows, mac, linux`
- `feat: инициализировать структуру python-пакета`
