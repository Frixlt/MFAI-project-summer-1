# Проект 2. Кодовое шифрование: учебная схема Мак-Элиса

**Тема:** Постквантовая криптография на основе кодов исправления ошибок.

**Цель проекта:** Реализовать учебную версию схемы Мак-Элиса и показать, как исправление ошибок
используется для шифрования.

---

## Идея

В кодовой криптографии сообщение кодируется с помощью линейного кода, затем в него специально
добавляется ошибка. Знать публичный код недостаточно: нужно уметь быстро исправлять ошибки. В
настоящей схеме Мак-Элиса секретом является структура кода, позволяющая эффективно декодировать.

---

## Задание

1. Реализовать операции над векторами и матрицами над полем \(GF(2)\):

   - сложение по модулю 2;
   - умножение матриц по модулю 2;
   - обращение бинарной матрицы, если это возможно.

2. Взять маленький код Хэмминга \([7, 4, 3]\). Можно использовать фиксированную порождающую матрицу
   \(G\) и проверочную матрицу \(H\).

3. Построить таблицу синдромов для исправления одной ошибки: \[\text{syndrome} = H \cdot c^T\]

4. Реализовать учебную схему Мак-Элиса:

   - `secret_key = (S, G, P)`
   - `public_key = G_pub = S * G * P`

   где:

   - \(S\) — случайная обратимая бинарная матрица \(4 \times 4\);
   - \(P\) — случайная перестановочная матрица \(7 \times 7\).

5. Реализовать шифрование 4-битного сообщения \(m\): \[c = (m \cdot G\_{\text{pub}} + e) \pmod 2\]
   где \(e\) — случайный вектор ошибки веса 1.

6. Реализовать расшифрование:

   - применить обратную перестановку;
   - исправить ошибку с помощью синдрома;
   - восстановить сообщение;
   - применить \(S^{-1}\).

7. Проверить корректность на всех 16 возможных 4-битных сообщениях.

8. Провести атаку грубой силой:

   - перебрать все сообщения;
   - перебрать все возможные ошибки веса 1;
   - показать, что маленькие параметры небезопасны.

9. Сравнить учебную схему с настоящими кодовыми KEM:
   - Classic McEliece;
   - HQC.

## Требования к Jupyter Notebook

В отчете должны присутствовать:

- Реализация арифметики над \(GF(2)\).
- Реализация таблицы синдромов.

- Проверка корректности работы на всех возможных сообщениях.
- Демонстрация атаки полным перебором (brute-force).
- Таблица размеров ключей и шифртекстов для учебной схемы.

### Минимальный успешный результат

Реализована маленькая схема Мак-Элиса на коде Хэмминга, она успешно шифрует и расшифровывает все 16
возможных 4-битных сообщений и демонстрирует, почему маленькие параметры не обеспечивают
безопасность.
